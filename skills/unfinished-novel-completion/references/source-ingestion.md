# Source Ingestion｜來源匯入

## 來源優先順序

1. 使用者合法提供的原稿／檔案。
2. 作者本人、官方出版方、編輯或遺產管理人公開資料。
3. 可核對的出版版本與可靠媒體／學術資料。
4. 粉絲維基、論壇、社群貼文只作線索，需降級並保留原 URL。

## 登記規則

用 `scripts/source_ingest.py register` 登記每個檔案，保存：

- `source_id`、標題、作者、類型、版本與章節範圍；
- 原始路徑或 URL、取得時間、檔案大小、SHA-256、完整／節錄狀態；
- 權利／使用狀態與是否由使用者提供；
- OCR、轉錄、翻譯或編輯加工註記。

不把整段受版權原文複製到證據帳本；只保存必要的短引文、位置與摘要。來源原檔與研究筆記分開。

## 版本處理

連載版、出版版、修訂版、翻譯版與改編版使用不同 `source_id`。用 `compare_source_versions.py` 產生差異報告，再把重要差異寫入 `version-conflicts.md`；不能因新版本方便就覆蓋舊版本。

## 完整度

記錄缺章、斷頁、OCR 錯字、未確認章名、被截斷的尾段與不可讀頁面。完整度未知時，降低可推測度，不用模型補齊來源。
