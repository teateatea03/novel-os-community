# Evidence and Intent｜證據與作者意圖

## 分層

| 層級 | 意義 | 可支持什麼 |
|---|---|---|
| `TEXT-CANON` | 已發表／定稿正文 | 角色已做的選擇、已建立的世界與伏筆 |
| `AUTHOR-NOTE` | 作者手稿、提綱、筆記 | 某一創作時點的計畫，不必然是最終意圖 |
| `AUTHOR-STATEMENT` | 作者本人訪談、公開留言 | 作者曾說過的方向，需記日期與上下文 |
| `EDITORIAL` | 編輯、出版社、遺產管理人 | 版本、授權、整理方式與出版脈絡 |
| `ADAPTATION` | 改編作品 | 只作獨立版本，不回填原作 |
| `FAN-THEORY` | 讀者或社群推論 | 候選解釋，不是正典或作者證據 |
| `INFERENCE` | 由多項材料推導 | 需列支持、反證與信心 |
| `PROPOSAL` | 補完新增內容 | 必須由作者核准才可進入計畫／正文 |

## 證據鏈

每個重要結論用：

```text
主張 → 來源 → 位置／引文 → 支持理由 → 反證／替代解釋 → 適用範圍 → 信心
```

不能用「作者風格像這樣」單獨證明情節意圖；風格只能支持呈現方式，不能代替劇情證據。

## 衝突處理

- 已發表正文與早期大綱衝突：保留兩者，正文列 `TEXT-CANON`，大綱列 `AUTHOR-NOTE`／`CONFLICTED`。
- 作者不同時期說法衝突：按日期與作品版本切分，不選最新說法當唯一真相。
- 粉絲理論得到後來正文部分支持：提升為 `INFERENCE`，仍不改標為作者意圖。
- 改編版本提供完整結局：只作另一條版本分支，除非權利人或作者明確指定。

## 最低證據標準

原意重建的核心結論最好有兩個獨立支持來源，或一個直接作者來源加正文相容性。只有單一轉述、搜尋摘要、粉絲留言或模型猜測時，最高只能列 `LOW`，不可鎖定。
