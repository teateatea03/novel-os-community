## 衝突時誰贏

1. 使用者最新指示、已定稿正文、人物知識權限、世界規則。
2. 作者樣本與 `style-sheet.md`。
3. 僅在宿主已安裝並確認來源／授權時，套用 `lieflat-less-ai-tone` 的白名單與豁免：未命中者逐字保留；它不允許的改動，本清單也不能做。
4. 本文件的 31 個檢查點。

無法確定是否空泛、重複或妨礙理解時，不改。

## 共用保留

- 不新增事實、數字、名字、日期、經歷、引文、來源、性能或因果。
- 「可能」不變「確定」，「計劃」不變「已經」，「被認為有關」不變「導致」。
- 不補造施事者、第四個列舉項、專家身份或下一步。
- 有功能的短句、排比、連接詞、被動、正式語和角色怪癖保留。
- 代碼、命令、路徑、URL、YAML、表格數據、標題錨點與引文不改。
- 小說裡的沉默、誤判、不漂亮句和視角偏見不是缺陷。

## A–F 只留觸發與邊界

| ID | 只在這種情況動 | 不要動 |
|---|---|---|
| 1 假對比 | 「不是 X 而是 Y」只抬語氣，否定側沒有新信息 | 兩側都有信息，或在糾正真實誤解 |
| 2 戲劇碎片 | 連續短句重複同一意思 | 短句帶新事實，或作者／角色有意強調 |
| 3 偽深度 | 格言不增加已寫出的判斷 | 被分析的格言、有助理解且含義清楚的比喻 |
| 4 起跑鋪墊 | 「讓我們深入看看」只預告下文 | 猶豫、未決定、需要再討論等實質態度 |
| 5 無對象辯護 | 沒有具體反對意見的自我辯白 | 真實限制、讀者會考慮的替代方案 |
| 6 強湊三段 | 三項只是同義空話 | 各自獨立的功能、事件、約束；不湊第四項 |
| 7 開頭復讀 | 連續句只因重複主語而拖 | 有意排比；各句的時間和動作都要留下 |
| 8 破折號 | 反覆製造揭曉，或蓋住分句關係 | 解釋、插入、轉折；無作者樣本也不一律刪 |
| 9 限定堆疊 | 同一層不確定性重複堆疊 | 證據強度、範圍、法律提示、真實修正 |
| 10 生造標籤 | 複合詞沒有已寫出的定義，妨礙理解 | 固定術語與必要英文連字 |
| 11 被動缺主語 | 施事者已寫出，改主動更清楚 | 施事者未知或不重要；不補「系統」「研究人員」 |
| 12 空泛高頻詞 | 賦能、至關重要、無縫等詞空泛或用詞不準 | 工程與文類裡有實義的正式詞 |
| 13 意義拔高 | 「標誌著新時代」沒有獨立內容 | 第一次、時間點、困難、作者明確判斷 |
| 14 模糊關聯 | 後文已寫明角色，前面還用空泛關係 | 角色確實不明時，保持概括 |
| 15 句尾拔高 | 「彰顯了……」只重複讚美 | 原因、目的、結果 |
| 16 宣傳語 | 讚美不改變讀者理解 | 已寫出的特徵；主觀評價不改成測試結論 |
| 17 借權威 | 未具名權威後面再加空泛價值 | 不把「專家認為」改成編造機構、報告或日期 |
| 18 回避是／有 | 系動詞繞圈，且不損失數量與範圍 | 「超過」不是「等於」，「可以提供」不是「已提供」 |
| 19 裝飾粗體 | 粗體不幫助定位 | 警告、長文跳讀重點、括號解釋 |
| 20 裝飾標題 | 表情符號、箭頭、分隔線妨礙閱讀 | 流程含義；文件標題與錨點另受保護 |
| 21 標點 | 中文正文誤用直引號或半形標點 | JSON、引語、使用者指定的「」或『』 |
| 22 客服腔 | 獨立文章裡的空問候、誇獎、希望有幫助 | 其中的實質信息；書信與客服回覆的禮貌 |
| 23 重複免責 | 同一資料缺口說兩次 | 時效、猜測邊界；不把缺口補成事實 |
| 24 首句復讀標題 | 標題後第一句沒有新信息 | 條件、定義、數據，即使用詞重複 |
| 25 談上一稿 | 「這段是剛補的」不屬於正文 | 變更日誌、版本差異；不推測新實作 |
| 26 層疊的的 | 長定語讓讀者回頭找中心名詞 | 不按字數機械刪；所有格關係要留 |
| 27 進行＋動詞 | 冗長且不承載時態、次數、範圍 | 「正在」不是「已經」，「計劃」不是「完成」 |
| 28 被字堆疊 | 與 11 相同，且主動句不改歸因 | 「被認為可能有關」保持不確定 |
| 29 四字排比 | 同義堆疊或與語域不符 | 四字節奏本身；各項獨立約束不合併 |
| 30 隨著發展 | 背景句沒有獨立信息 | 已寫出的趨勢、時間或因果 |
| 31 套話收尾 | 祝願或重複讚美不提供信息 | 有內容的總結、情緒、行動計劃；不編下一步 |

## 小說額外邊界

- 角色嘴硬、答非所問、說不出口，不是 5 或 22。
- 視角人物的錯誤判斷不是 3；不要改成全知正確說明。
- 重複意象若每次壓力或關係不同，不是 7。
- 台灣繁中、年代用詞、職業術語優先於「像不像模板」。
- 章後只記錄用過的檢查點編號。空清單合法。不輸出 AI 分數。
