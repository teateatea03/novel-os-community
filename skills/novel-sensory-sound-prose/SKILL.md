# Novel Sensory & Sound Prose

通用**感官／聲音文筆**技能。目標：讓場景「聽得到、碰得到」，不是只看得到動作清單。

本技能服務**所有題材**（日常、動作、親密、科幻、對話場）。親密場景只是高需求子集，規則不鎖死在肉戲。

## 與其他技能的邊界

| 技能 | 管什麼 | 本技能不搶 |
|---|---|---|
| `novel-style-craft-director` | 敘事距離、節奏契約、流派工藝 | 不代替整份 style contract |
| `novel-human-voice-editor` | 去 AI 腔、角色同聲、台灣繁中自然度 | 本技能先補聽感；人味修訂可後做 |
| `general-intimacy-craft` / 角色 intimacy card | 同意、能動、關係功能、角色專屬親密聲 | 本技能只補感官通道，不改同意／事件 |
| `long-form-novel-writer` / 互動 runtime | 正典、狀態、Gate | 本技能不 commit 世界狀態 |

優先序：作者指示 → 正典／視角／人物權限 → 場景因果 → **感官可感度** → 詞藻漂亮。

## 何時啟用

- 「太安靜」「沒聲音」「缺狀聲詞」「聽不到」
- 「肉戲／打戲／浴室／廚房太平淡」
- 「加強五感／觸覺／水聲／呼吸聲」
- 「寫成通用文筆規範／技能，不要只修這一場」
- 診斷正文是否只有視覺動作鏈

## 核心模型：聲音三層 + 一句反應

每一處需要聽感的節拍，最多寫：

1. **聲源**（誰／什麼在響）
2. **聲質**（一個具體聽感：濕、悶、尖、斷、遠）
3. **POV 反應或後果**（他因此停、聽不清、被嚇、更硬、更窘）

不要：連續三個狀聲詞疊加、也沒有人反應。

```text
壞：噗通、嘩啦、嗯嗯啊啊。
好：她坐下時水聲悶悶地推開一圈；你聽得見自己喉結滾了一下。
```

## 狀聲詞紀律（繁中小說）

### 可用

- **嵌進句子**的擬聲／聽感動詞：拍、磕、嗆、嗡、砸、嗑、悶響、水花碎開
- **偶發、短、有功能**的狀聲：喀、咚、嘶、嗯（且後面有反應）
- **重複表持續**：滴答、滴答——用來拖延或焦慮，不是裝飾

### 慎用／少用

- 漫畫式獨立狀聲行：`「啪！」` `「啊～～」`（除非作品本來就是輕小說／漫畫感契約）
- 長串嬌喘擬聲充字數
- 英文 bang/crash 硬塞進台灣繁中敘事（除非角色／媒介需要）
- 同一頁重複同一個狀聲超過 2 次

### 格式（預設文學敘事）

1. **優先**：把聲音寫成謂語或名詞化聽感，不獨立成行  
   - `膝骨在池底磕了一下`  
   - `門軸拉出一條細響`
2. **次選**：短狀聲貼在動作後，逗號接後果  
   - `杯底磕上磁磚，喀，兩人都頓住。`
3. **少用**：全大寫、一串驚嘆號、獨立擬聲段落

詳細詞庫與分場景示例 → `references/sound-banks-zh-TW.md`  
外部研究摘要 → `references/research-sources.md`

## 五感優先序（依場景類型）

不要五感點名。每段只主攻 **1–2 感**。

| 場景 | 優先 | 次要 | 常被濫用 |
|---|---|---|---|
| 親密／浴池 | 觸 + 聽 | 溫度 | 全景身體目錄、反覆「喘息」 |
| 對話／客廳 | 聽 + 視距離 | 觸（杯、布） | 心情形容詞 |
| 動作／追逃 | 聽衝擊 + 觸痛 | 視閃光 | 慢動作解剖 |
| 廚房／日常 | 聽 + 嗅 | 觸熱 | 菜單式描寫 |
| 恐怖／緊張 | 聽遠近 + 觸膚 | 視死角 | 解釋恐懼 |
| 科幻／機械 | 聽機械節奏 + 觸震動 | 視 HUD | 規格朗读 |

## 工作流

### A. `diagnose`（診斷）

對目標文本逐段標：

- `VIS_ONLY`：只有看得見的動作
- `SOUND_FLAT`：有「聲音」字樣但無可辨聽感
- `ONO_SPAM`：狀聲詞過密或漫畫化
- `ONO_NAKED`：狀聲無聲源／無後果
- `BREATH_SPAM`：呼吸／心跳模板過密
- `SENSE_CHECKLIST`：五感打卡式
- `GOOD_AUDIO`：聲源＋聲質＋反應齐全

輸出：問題表 + 最高優先 3 個修法，不先大改情節。

### B. `enrich`（加聲／加感）

規則：

1. **不新增正典事件**（除非作者要求）。  
2. 每個主要動作節拍補 **一個** 聽感或觸感通道。  
3. 刪除無效狀聲，再加有效聽感（先瘦身再 enrichment）。  
4. 保持 POV：只寫視角角色聽得到、辨得出的聲音。  
5. 角色語音（台詞風格）不靠狀聲詞冒充；台詞仍走角色卡。

Enrichment 插入點優先：

- 動作接觸瞬間（坐進水、門關上、杯落地）
- 語言被環境蓋過（水聲太大聽不清）
- 尷尬／恐懼的空白（房間太靜）
- 高潮／轉折的「一個」聲響（不是一連串）

### C. `checklist`（提交前）

- [ ] 場景是否至少有 **2 處** 可辨聽感（非「很安靜」空話）？  
- [ ] 狀聲詞是否都有聲源與後果？  
- [ ] 是否連續 3 句都在報身體部位／動作指令？若是，插入聽／觸中斷。  
- [ ] 呼吸／心跳／喉結是否成模板群？  
- [ ] 親密場：水／床／布料是否影響動作（阻力、悶聲、濕響）？  
- [ ] 讀出聲：有無節奏（長句後短響、短句後餘韻）？

### D. `bank`（開詞庫）

需要選詞時讀 `references/sound-banks-zh-TW.md`，**改寫進句**，禁止整排貼上。

## 親密／露骨場景的聲音層（通用）

不取代 intimacy craft。只規定聽感：

1. **環境底噪**一條就好：排水嗡聲、遠電視、水管。  
2. **接觸聲**優於呻吟擬聲：水被擠開、皮膚拍水、膝磕池壁、髮絲貼濕肩的細響。  
3. **人聲**用功能分類，不要用「啊」填滿：  
   - 壓抑（悶在肩上）  
   - 漏出（半句「等」）  
   - 言語（罵、指示、確認）  
4. 同一場為每個角色保留 **不同的人聲策略**（一個多話／一個幾乎不叫）。  
5. 高潮：一個聲＋一個身體後果；禁止多輪「啊啊」升級。

肉戲事件密度高時：寧可拆場，也不要用狀聲詞掩蓋清單感。

## 反模式

| 反模式 | 例子 | 修法 |
|---|---|---|
| 擬聲雨 | 啪啪啪嗯嗯水聲嘩啦 | 留一個接觸聲 + 一句人話 |
| 無聲動作鏈 | 他伸手→她轉過→進入→射 | 每 2 個動作插 1 聽／觸 |
| 說明音量 | 「很大的聲音」 | 改聲質與後果：聽不清話／耳膜一緊 |
| 五感打卡 | 看見…聽見…聞到… | 刪到 1–2 感 |
| 呼吸模板 | 呼吸亂了×N | 換：咬字斷了／水聲蓋過吸氣 |
| 角色同喘 | 兩人一樣「輕喘」 | 一人罵、一人咬肩悶住 |

## 與寫作產出的銜接

1. 規劃場景功能（style / intimacy / long-form）後，**起草前**用本技能選 1 條環境底噪 + 2 個接觸聲預算。  
2. 初稿後跑 `diagnose` → `enrich`。  
3. 再交 `novel-human-voice-editor` 去機器腔。  
4. 專案若有 prose gate，可把 `ONO_SPAM` / `VIS_ONLY` 大面積命中當人工複核項（本技能不強制改 gate，除非作者要求）。

## 產出物

- 診斷表或修訂正文  
- 可選：把穩定規則回寫到作品 `style-sheet.md` 的「聽感／感官」節  
- 通用規則留在本 skill；作品特例不要寫死進 skill

## 快速範例（浴池，非正典）

**弱：**  
她坐下，開始動。水很熱。他喘了。

**強：**  
她坐下時，池水往外推了一圈，拍在瓷磚上又折回來。你想說話，聲線被下一次水聲切成兩半。
