# 感官／聲音文筆研究來源摘要

狀態：research baseline for skill v1.0.0  
收集：2026-08-10  
原則：只採可交叉驗證的工藝；不抄錄他人小說露骨原文。

## 聲音／狀聲詞

### Writing Beginner — How to Write Onomatopoeia
https://www.writingbeginner.com/how-to-write-onomatopoeia/

可採：
- 狀聲是沉浸捷徑，但須匹配場景強度
- 分類：衝擊／自然／人聲／動物／機械
- 格式工具：斜體、短促、重複表持續、拉長表拖延（文學小說從嚴）
- **務必節制**；過多像卡通
- 與其他感官描寫平衡，不能只靠狀聲

### Method Writing — Sensory writing: sounds, music
https://method-writing.com/sensory-writing-sounds-music/

可採：
- 不只「寫到聲音」，還可用節奏、反覆、音韻讓句子本身有聽感
- 日常擬聲與句節奏可並用
- 聲音可編排情緒曲線（遠→近、底噪→突變）

### Proofreading / Oxbridge 系說明文（交叉）
How to write sound effects / onomatopoeia usage

可採：
- 聲效服務氛圍與節奏，不是裝飾貼紙
- 描寫性聽感（the thud of…）與純擬聲可混用；文學敘事前者通常更穩

## 親密場景中的感官（與聲音相接）

### Write for Harlequin — Avoiding the Ick Factor (2019)
https://www.writeforharlequin.com/avoiding-the-ick-factor-how-to-write-sex-scenes-that-draw-the-reader-in-and-add-to-your-plot/

可採：
- 缺感官（含聽）只剩視覺動作 → 旁觀感／ick
- 感官必須接到角色「覺得如何」
- 動作→反應；結束後情感狀態要變

### Anna Campbell — Getting Intimate with Point of View
https://annacampbell.com/articles/getting-intimate-with-point-of-view/

可採：
- Deep POV：聲音也只透過當下視角過濾
- 少 filter；內心語言要像那人說話

### The Novelry — Claire Daverley, How to Write Intimacy (2026)
https://www.thenovelry.com/blog/how-to-write-intimacy

可採：
- 說與不說
- 感官建立氣氛
- **觸覺單獨升級**；接觸聲常比呻吟清單有用

### Inkitt — How to Write Intimate Scenes (2024)
https://www.inkitt.com/writersblog/how-to-write-intimate-scenes

可採：
- 細節集中在兩人之間
- 要有 buildup 與 aftermath
- 同意與界線

## 技能化結論（寫進 SKILL 的部分）

1. 聲源 + 聲質 + POV 後果  
2. 狀聲詞嵌句優先，獨立擬聲少用  
3. 每段 1–2 感；親密優先觸+聽  
4. 人聲按功能，不按「叫得多」  
5. 沉默／底噪是設計工具  
6. 先 diagnose 再 enrich；不靠擬聲雨掩蓋動作清單  

## 明確不採

- 教人整段複製他書色情描寫  
- 把漫畫擬聲當所有成人文學預設  
- 以「更黃的狀聲詞表」替代角色與關係
