# 繁中聽感／狀聲詞庫（選用，禁止整排貼上）

用法：每場先定**聲源**，再從對應桶選 **1 個**聽感詞嵌入句子；不要連續堆疊。

標記：
- `嵌` = 宜嵌句（優先）
- `狀` = 可作短狀聲，須接後果
- `慎` = 易卡通／易模板，限類型契約

---

## 1. 水／浴／雨

| 聽感 | 類 | 嵌入方向 |
|---|---|---|
| 拍、拍打、拍上瓷磚 | 嵌 | 水對硬面 |
| 湧、漫、溢 | 嵌 | 水位移動 |
| 濺、細碎的水花 | 嵌 | 動作幅度大 |
| 汩汩、排水的悶響 | 嵌 | 底噪 |
| 滴、滴答 | 嵌/狀 | 安靜拖延 |
| 嘩（一聲） | 狀/慎 | 大量瀉下，勿連續 |
| 撲通 | 狀/慎 | 落水；成人敘事少用連續 |
| 滋、細響 | 嵌 | 濕皮膚摩擦 |

句模：
- `水被擠開，又合上，悶悶的。`
- `池沿接住一圈水聲，又滑回去。`
- `排水口在腳邊低低地嗡。`

---

## 2. 身體接觸／親密（非呻吟清單）

| 聽感 | 類 | 說明 |
|---|---|---|
| 濕響、黏膩的細聲 | 嵌 | 接觸面有水／汗 |
| 拍（皮膚輕拍水面） | 嵌 | 節奏感 |
| 磕、碰（膝、肘、骨） | 嵌 | 空間窄 |
| 咬合的短響／齒間漏出的氣 | 嵌 | 壓抑 |
| 吞嚥、喉結一滾 | 嵌 | 緊張／事後 |
| 布料黏開的一聲 | 嵌 | 有衣物時 |
| 床架輕響、靠墊泄氣聲 | 嵌 | 非浴場 |
| 嗯、唔、嘶 | 狀 | **極短**，且角色差異化 |
| 啊、哈、嬌喘擬聲串 | 慎 | 預設禁止當主描寫 |

人聲功能桶（選功能，不選「叫得多」）：
- 壓抑：悶在肩上、咬住、字斷在齒間  
- 漏出：半句「等」「慢」  
- 言語：罵、指示、確認、玩笑  
- 事後：啞、嗓子毛、笑了一聲又停  

---

## 3. 呼吸／嗓（易模板，限額）

每場每人預設最多 **2** 次呼吸描寫；超過先改成別的通道。

| 可用 | 少用 |
|---|---|
| 吸氣被水聲切開 | 呼吸亂了 |
| 字到一半沒氣 | 劇烈喘息 |
| 嗓子發乾、啞 | 嬌喘不已 |
| 笑噴在鎖骨上 | 心跳如鼓（泛用） |

## 4. 門、屋、日常

| 聲 | 類 | 場景 |
|---|---|---|
| 喀、咔 | 狀 | 鎖、杯、開關 |
| 吱、細響 | 嵌 | 舊門軸（可拉長「細——」慎用） |
| 咚、悶響 | 嵌/狀 | 重物、關門 |
| 沙沙 | 嵌 | 袋、葉、布 |
| 嘶嘶 | 嵌 | 爐火、泄氣 |
| 嗡 | 嵌 | 冰箱、燈、艦體 |
| 嘀、嗶 | 嵌/慎 | UI／設備；科幻可略增 |
| 電視壓低的人聲 | 嵌 | 底噪，不必聽清詞 |

---

## 5. 動作／撞擊

| 聲 | 類 |
|---|---|
| 撞擊的悶響、骨與骨 | 嵌 |
| 破（玻璃）的尖碎 | 嵌 |
| 擦過地面的刺聲 | 嵌 |
| 拳進布面的短促聲 | 嵌 |
| 砰／咚 | 狀，一場一次為限 |

打戲同樣遵守：聲 + 痛／失衡後果，不用擬聲代替力學。

---

## 6. 沉默也是聲音設計

有時最強聽感是「突然沒聲」：

- 水聲停半拍  
- 話到嘴邊被房間的靜按回去  
- 只能聽見自己耳裡的血聲（慎：易 Melodrama，限高壓場）

---

## 7. 組合公式（複製後改寫）

1. `〔動作〕時，〔聲源+聲質〕。〔POV 後果〕。`  
2. `你想說〔話〕，〔環境聲〕把它切成兩半。`  
3. `〔短狀聲〕，〔兩人反應〕。`  
4. `先是〔遠/底噪〕，接著〔近接觸聲〕，最後〔人聲功能〕。`

---

## 8. 角色差異（聲音策略）

為每個角色在作品卡上註一條即可：

| 角色類型 | 聲音策略例 |
|---|---|
| 嘴硬 | 多言語、少浪叫；罵聲清楚 |
| 內斂 | 幾乎不叫；齒間、吞嚥、手用力 |
| 慌 | 話多且碎；碰到東西的磕碰聲多 |
| 掌控 | 指令短；環境被他安靜下來 |

禁止全場統一「輕喘＋悶哼」。

---

## 9. 翻譯腔／AI 聲感黑名單（出現就改）

- 充滿情慾的呻吟  
- 無法抑制的喘息  
- 淫靡的水聲（說明情緒，不寫聲質）  
- 一次又一次的撞擊聲（無聲質無次數感）  
- 空氣中瀰漫著…（空嗅覺）  
- 只有彼此的呼吸聲（無差別萬用收尾）
