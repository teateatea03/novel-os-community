# 歷史、武俠、古典群像、愛情與家族史詩工藝

## 1. 歷史小說／制度中的私人命運

**代表人物**：Leo Tolstoy、Hilary Mantel（已故）、司馬遼太郎。

### 可泛化技巧
- 歷史力量透過稅、軍役、交通、疾病、文書、繼承與名聲限制個人。
- 公共事件不是背景說明，而改變角色可見選項和關係。
- 近距視角保留時代認知：角色不知道後世結論。
- 歷史人物可有推論性內心，但要區分史實、合理推論與創作提案。

### 場景引擎
私人目標遇到制度／時代限制 → 角色使用其階級和知識能想到的策略 → 公共後果進入私人關係。

### 長篇規則
- 維護「當時已知／後世已知」兩套資訊。
- 正確細節只在改變阻力、成本或選擇時展開。
- 不讓主角以現代詞彙無代價地超越所有同時代人。

### 常見誤用
資料傾倒、古人穿舊衣說現代話、名人到處客串、歷史事件自動替人物完成弧線。

## 2. 武俠／武德、江湖與招式因果

**代表人物**：金庸、古龍（皆已故）、梁羽生。

### 可泛化技巧
- 武功同時是身體技術、師承關係、道德選擇與社會身分。
- 江湖由門派、恩怨、名聲、承諾、資源和官府邊界構成。
- 對決的勝負不只看強弱，也看情報、地形、傷勢、心理、招式相剋與不願付出的代價。
- 金庸傳統可借鑑群像、歷史／江湖交錯和人物成長；古龍傳統可借鑑留白、短促對峙和危機前的心理張力。不要混成表面古風腔。

### 場景引擎
承諾／恩怨要求人物行動 → 身分與武德限制可用手段 → 對決迫使人物暴露真正價值 → 勝負改變名聲和關係網。

### 長篇規則
- 每門武功記錄能力、距離、前置、成本、破綻和已知者。
- 傷勢、內力、兵器與旅程持續影響後續。
- 高手不能為襯托主角反覆降智；勝負需有先前線索。
- 武德要由選擇和代價展示，不靠旁白封聖。

### 常見誤用
招式名稱取代空間動作、內力無限、門派全員一性格、女性只作獎賞、古風詞藻與歷史制度脫節。

## 3. 中國古典章回／多線群像

**代表人物／作品傳統**：曹雪芹《紅樓夢》、施耐庵《水滸傳》、羅貫中《三國演義》。作者歸屬與版本問題需依研究處理。

### 可泛化技巧
- 以宴席、節令、家務、禮制與物件串聯龐大群像。
- 人物可透過稱謂、座次、詩文、禮物、傳話和僕役網絡間接互動。
- 伏筆埋在日常細節、判詞、傳聞或重複物件中，回收時改變其意義。
- 章回節點可在一條線暫停時切到另一條因果上，形成期待。
- 群像人物可有鮮明功能，但不能只剩固定綽號和單一性格。

### 場景引擎
公共禮俗聚合多人 → 私人欲望在規矩中碰撞 → 消息沿關係網變形 → 一個小失禮造成長期後果。

### 長篇規則
- 維護稱謂矩陣、家族／主僕／門生關係和消息傳遞路徑。
- 切線前留下具體未完成動作或承諾，切回時先交代時間差。
- 角色再次登場要以欲望和狀態辨認，不只重述身分。

### 常見誤用
仿古詞彙堆積、旁白替人物定性、角色太多但關係不動、章末只用制式套語。

## 4. 愛情小說／關係選擇

**代表人物**：Jane Austen、Charlotte Brontë、E. M. Forster；當代作者只提煉類型高層工藝。

### 可泛化技巧
- 吸引不是結局；關係弧由認識、誤讀、信任證據、脆弱、修復和共同選擇構成。
- 外部阻力若不改變人物理解，只會拖延；內外衝突應互相作用。
- 權力、金錢、身分、名聲、性別規範與未來計畫進入愛情成本。
- 親密場景揭示人物如何照顧、測試、控制、撤退或修復。

### 場景引擎
兩人各自追求需求 → 對對方行為形成誤讀 → 新證據提高吸引或風險 → 必須選擇脆弱、控制、撤退或修復。

### 長篇規則
- 每一關係進展必須有可觀察信任證據，不用作者宣告化學反應。
- 衝突不能只靠可一句話消除的誤會，除非不說的代價已建立。
- 結局的核心是雙方作出的選擇與可持續關係條件，不只是接吻／結婚。
- 依附模型是條件式假說，不能把控制、傷害浪漫化。

### 常見誤用
救命等於愛、嫉妒等於深情、騷擾等於執著、配角只負責助攻、身體吸引替代價值與生活相容。

## 5. 家族史詩／代際記憶

**代表人物**：Thomas Mann、Gabriel García Márquez、巴金。

### 可泛化技巧
- 家族制度透過財產、名字、祕密、照顧責任與重複選擇跨代傳遞。
- 相似事件在不同世代產生變奏，顯示時代和人物能動性的差異。
- 物件、房屋、食物、儀式或稱謂可承載記憶，但每次出現要改變含義。
- 家族傳說與實際紀錄可以互相矛盾。

### 場景引擎
當代人物面臨選擇 → 家族規則和未結債務施壓 → 他重演、反抗或誤解前代模式 → 結果成為下一代的新傳說。

### 長篇規則
- 維護族譜、年齡、繼承、稱謂和事件重疊表。
- 同名人物要有明確語言、欲望和時代辨識。
- 每次回溯必須改變當代人物對選擇的理解。

### 常見誤用
年代跨度大但只有摘要、苦難堆疊、女性只負責生育、每代重複卻沒有差異。
