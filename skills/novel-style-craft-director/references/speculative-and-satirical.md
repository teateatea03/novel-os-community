# 科幻、奇幻、魔幻寫實與諷刺工藝

## 1. 科幻／推想的二階後果

**代表人物**：H. G. Wells、Ursula K. Le Guin、Octavia E. Butler、Liu Cixin／劉慈欣（在世；只用高層工藝）。

### 可泛化技巧
- 從一個假設出發，追問它如何改變家庭、工作、法律、戰爭、信仰、語言與不平等。
- 世界設定應進入角色日常選擇，不以百科段落自我展示。
- 科學或技術不是單純道具，而會製造新權力、依賴與倫理成本。
- 觀念規模可以巨大，但仍需由具體人物承擔不可逆代價。

### 場景引擎
新技術／環境規則提供能力 → 制度和他人重新配置 → 原解法產生二階問題 → 人物必須改變價值或聯盟。

### 長篇規則
- 為核心推想建立：可做、不可做、成本、普及程度、誰控制、社會適應。
- 每一項重大設定至少影響兩個不同社會層級。
- 說明只在人物需要做決定時出現。
- 技術解法應有先前建立的能力與代價，避免機械降神。

### 常見誤用
百科傾倒、科技只有名稱、人物只是理念喇叭、尺度很大但私人代價為零。

## 2. 奇幻／神話與權力系統

**代表人物**：J. R. R. Tolkien、Ursula K. Le Guin、N. K. Jemisin（在世；只用高層工藝）。

### 可泛化技巧
- 地名、語言、傳說和制度互相支持，產生歷史厚度。
- 魔法的用途、代價、禁忌和權力分配會形成社會結構。
- 旅程不是地圖打卡；每一地區迫使人物面對不同價值或聯盟。
- 神話可成為人物相信的歷史，不必全是客觀真相。

### 場景引擎
角色依已知規則求解 → 遭遇規則的社會／倫理成本 → 必須選擇使用權力、拒絕權力或改變關係。

### 長篇規則
- 世界規則先過「為什麼沒有徹底改變所有日常生活」測試。
- 神祕可以保留，但不能在高潮任意新增能力。
- 對每個文化至少寫出內部分歧，避免單一種族等於單一性格。

### 常見誤用
專有名詞洪水、設定資料庫大於故事、善惡族群本質化、魔法成本只在作者需要時出現。

## 3. 魔幻寫實／歷史現實的異常

**代表人物**：Gabriel García Márquez、Jorge Luis Borges（亦屬形上幻想）、Isabel Allende。

### 可泛化技巧
- 異常以平靜、具體、日常語氣呈現；人物反應由文化記憶和社群規則決定。
- 超常不是逃離歷史，而可具象化殖民、暴力、記憶、失蹤、家族循環與官方沉默。
- 集體傳說、家族口述和制度紀錄可構成互相競爭的真實。
- 時間可循環或重名，但讀者仍需情感與因果錨點。

### 場景引擎
歷史／家庭壓力無法以日常語言承載 → 異常成為共同現實 → 社群用習俗或否認吸收它 → 被壓抑的代價再次出現。

### 長篇規則
- 先建立敘事共同體為何接受異常。
- 魔幻事件須改變關係、記憶或權力，而非只供視覺奇觀。
- 對地域、殖民與宗教脈絡做研究；不要把「拉美感」簡化成花朵、鬼魂和炎熱。

### 常見誤用
把所有無解事件都稱魔幻寫實、異國裝飾、忽略政治歷史、任意規則破壞因果。

## 4. 反烏托邦／政治寓言

**代表人物**：George Orwell、Aldous Huxley、Margaret Atwood（在世；只用高層工藝）。

### 可泛化技巧
- 壓迫透過語言、程序、工作、家庭、生育、娛樂和自我審查進入日常。
- 制度不是一群純壞人，而有獎勵、依賴、信念和責任分散。
- 世界規則在小型生活選擇中被讀者理解。
- 主角的反抗要面對物質與關係代價，不只發表正確演說。

### 場景引擎
日常制度要求服從 → 人物為私人需求微小違規 → 系統透過關係／資源回應 → 微小違規變成身份危機。

### 長篇規則
- 定義制度如何取得合法性、資訊和合作。
- 讓不同階層對制度有不同利益與理解。
- 口號、禁語和官樣文章只低頻出現，重點是它們如何改變行為。

### 常見誤用
反派政府無所不能又極度愚蠢、世界只為單一論點存在、角色全是立場代言人。

## 5. 諷刺／荒誕制度

**代表人物**：Jonathan Swift、Nikolai Gogol、Franz Kafka、Kurt Vonnegut。

### 可泛化技巧
- 將制度的一條隱含邏輯推到可見但仍自洽的程度。
- 敘述語氣可冷靜接受荒謬，使讀者自行看見暴力。
- 人物試圖遵守規則時，規則反而生成更大矛盾。
- 重複程序、稱謂和文件可製造節奏與壓迫，但每次要升級後果。

### 場景引擎
人物提出合理需求 → 制度要求不可能證明／程序 → 人物越配合越被定義成有問題 → 私人身份被行政語言吞噬。

### 長篇規則
- 諷刺目標要具體：哪個權力機制、誰承擔代價。
- 荒誕世界仍需穩定局部規則，否則只剩隨機。
- 笑點之後保留人的損失，避免只有段子。

### 常見誤用
每句都機智、角色沒有情感現實、荒誕等於無規則、隱喻只有一對一答案。
