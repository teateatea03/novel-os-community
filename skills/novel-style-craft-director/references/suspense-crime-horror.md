# 懸疑、犯罪、驚悚與恐怖工藝

## 1. 古典偵探／公平解謎

**代表人物**：Edgar Allan Poe、Arthur Conan Doyle、Agatha Christie、Dorothy L. Sayers。

### 可泛化技巧
- 犯罪／謎題有一個可被重建的事件鏈。
- 關鍵線索在揭曉前公平出現，但可因錯誤框架而被忽略。
- 紅鯡魚必須來自人物合理行為或證據多義性，不是作者說謊。
- 偵探的觀察、推理與驗證分開；猜中不等於破案。
- 揭曉同時重解讀先前場景，並結算人的欲望與代價。

### 場景引擎
新證據 → 改變嫌疑分配 → 某人反制或說謊 → 驗證產生更窄的新問題。

### 長篇規則
- 建立真相時間線、讀者線索表、偵探知識表、每名嫌疑人的表面與真實動機。
- 解答所需核心線索至少在揭曉前出現；不能依未介紹的專業知識單獨定罪。
- 每次查問都應改變資訊、關係或風險，不能只是收集口供。

### 常見誤用
藏起關鍵事實、兇手最後一章才登場、偵探靠直覺神諭、紅鯡魚與真相毫無因果關係。

## 2. 黑色犯罪／道德壓力

**代表人物**：Dashiell Hammett、Raymond Chandler、Patricia Highsmith。

### 可泛化技巧
- 案件是進入權力、金錢與腐敗網絡的門，不只是拼圖。
- 調查者的道德界線在每次妥協中受測。
- 城市和制度透過交易、空間、工作及階級成為主動阻力。
- 犯罪者的視角可製造「會不會露餡」而非「是誰做的」懸念。

### 場景引擎
人物需要某資源／真相 → 必須向有代價的人交易 → 局部成功使他更深捲入。

### 長篇規則
- 每個重大線索同時揭示一項權力關係。
- 暴力會帶來身體、法律、關係或心理後果，不能重置。
- 冷硬比喻要符合視角人物經驗，且低頻使用。

### 常見誤用
只複製犬儒腔、酒與煙；女性角色全成誘惑工具；暴力沒有後果。

## 3. 間諜／政治驚悚

**代表人物**：John le Carré、Eric Ambler、Graham Greene。

### 可泛化技巧
- 資訊不是物件而已，還牽涉來源、可信度、動機與機構利益。
- 忠誠可分成國家、組織、同僚、家庭和自我形象，多者衝突。
- 真正張力常來自等待、驗證、監視和不確定，而非連續追車。
- 制度用程序、語言和責任轉移塑造個人選擇。

### 場景引擎
收到不可完全信任的情報 → 在有限時間內選擇相信誰 → 行動暴露新的忠誠裂縫。

### 長篇規則
- 維護來源鏈與「誰認為誰知道什麼」。
- 反轉要改變情報意義，不抹除先前所有因果。
- 機構不能全知；各部門有競爭、延遲和自保。

### 常見誤用
人人無限多重間諜、用晦澀代替複雜、反轉只靠隱藏資料。

## 4. 恐怖／哥德

**代表人物**：Edgar Allan Poe、Shirley Jackson、H. P. Lovecraft（使用時需批判其偏見與文化局限）、Stephen King（在世；只提煉高層工藝）。

### 可泛化技巧
- 恐怖來自安全模型被逐步破壞：家、身體、群體、理性或宇宙位置不再可靠。
- 先建立普通生活與可失去之物，異常才有尺度。
- 重複細節每次增加差異，使讀者先於角色察覺模式。
- 不確定性要控制：讀者可不知原因，但必須知道危險如何逼近。
- 群體恐怖常透過禮貌、否認、排斥和共同規範運作。

### 場景引擎
日常規則 → 小異常 → 合理解釋 → 異常重現且成本升高 → 人物選擇相信／否認 → 安全邊界縮小。

### 長篇規則
- 定義恐懼機制：未知、污染、失控、被看見、孤立、身分瓦解等。
- 驚嚇之後要更新人物的行為與資源，不能恢復原狀。
- 怪物／超自然規則可部分未知，但表現不能任意方便劇情。
- 不以精神疾病、族群、身體差異或未知文化直接等同邪惡。

### 常見誤用
只堆血腥、夢醒重置、角色反覆做不合理決定、靠突然巨響取代恐懼累積。

## 5. 驚悚節奏工具

**代表人物**：不綁單一作者；綜合犯罪與間諜傳統。

- 壓力由「目標＋時限＋資訊不足＋失敗代價」構成。
- 每次脫困至少付出資源、暴露、傷勢、關係或道德代價之一。
- 交替使用壓縮場景與後果場景；全程高速會使危機失去差異。
- 章末問題應具體：「他必須在誰到達前做什麼」，不是抽象「危險才開始」。
