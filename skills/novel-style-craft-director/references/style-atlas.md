# 小說風格工藝圖鑑

用於快速選型。代表人物只是技術座標；實際寫作需讀對應參考包並建立原創風格契約。

| 類型／傳統 | 代表人物（例） | 主場景引擎 | 最適合 | 主要風險 |
|---|---|---|---|---|
| 社會寫實 | Austen、Eliot、Flaubert | 私欲在禮節／制度中洩漏 | 階級、婚姻、群像 | 只剩古典腔與慢節奏 |
| 心理寫實 | Dostoevsky、漱石 | 自我理由競爭並造成行動 | 道德困境、人格裂縫 | 獨白取代事件 |
| 現代主義 | Woolf、Joyce、Proust | 感官觸發時間與記憶 | 主觀時間、認知變化 | 碎片無因果 |
| 極簡 | Hemingway、Carver | 表面任務洩漏隱藏衝突 | 潛台詞、日常危機 | 必要資訊也被刪除 |
| 日本近代內省 | 漱石、芥川、太宰 | 社會角色與自我表演衝突 | 疏離、羞恥、不可靠自述 | 陰鬱機械重複 |
| 古典偵探 | Poe、Doyle、Christie、Sayers | 新證據改變嫌疑與驗證 | 公平解謎、封閉嫌疑圈 | 作者藏關鍵資料 |
| 黑色犯罪 | Hammett、Chandler、Highsmith | 交易使人物更深陷權力網 | 腐敗、道德妥協、城市 | 犬儒腔與無後果暴力 |
| 間諜驚悚 | le Carré、Ambler、Greene | 不可靠情報逼迫忠誠選擇 | 制度、政治、雙重身分 | 無限反轉、資訊作弊 |
| 恐怖／哥德 | Poe、Jackson 等 | 安全模型逐步崩解 | 家庭、群體、未知威脅 | 血腥取代恐懼 |
| 科幻 | Wells、Le Guin、Butler 等 | 推想造成制度二階後果 | 科技倫理、文明尺度 | 百科傾倒、人物工具化 |
| 奇幻 | Tolkien、Le Guin 等 | 權力規則與倫理成本衝突 | 神話、旅程、文明 | 設定大於故事 |
| 魔幻寫實 | Márquez、Allende 等 | 異常承載歷史／集體記憶 | 家族、殖民、失蹤、循環 | 異國裝飾、任意魔法 |
| 反烏托邦 | Orwell、Huxley 等 | 微小違規引發制度反制 | 政治、語言、身體治理 | 角色成論點喇叭 |
| 荒誕諷刺 | Swift、Gogol、Kafka | 遵守程序反而加深矛盾 | 官僚、制度、身份 | 隨機怪誕、只有段子 |
| 歷史小說 | Tolstoy、Mantel、司馬遼太郎 | 私人目標撞上時代限制 | 制度、戰爭、政治 | 資料傾倒、現代人穿越 |
| 武俠 | 金庸、古龍、梁羽生 | 恩怨／承諾受武德與能力限制 | 江湖群像、對決、成長 | 招式名取代因果 |
| 古典章回群像 | 曹雪芹等作品傳統 | 禮俗聚人、消息沿關係網變形 | 大家族、多線人物 | 稱謂混亂、人物扁平 |
| 愛情 | Austen、Brontë、Forster | 誤讀與信任證據逼迫關係選擇 | 關係弧、價值相容 | 嫉妒／控制浪漫化 |
| 家族史詩 | Mann、Márquez、巴金 | 家族規則跨代重演／反抗 | 多世代、記憶、財產 | 年代只有摘要 |
| 成熟成人題材 | Wharton、Tolstoy、Baldwin | 私欲與婚姻／名聲／權力相撞 | 背叛、照護、道德灰區 | 成人被誤解成只剩性 |
| 成人親密／情色 | Lawrence、Nin、Duras、Colette | 試探、同意、身體與關係後果 | 慾望、自我認知、親密權力 | 物化、脅迫浪漫化、無後果 |

## 按讀者體驗選擇

- **想讓讀者推斷**：極簡、黑色犯罪、自由間接引語。
- **想讓讀者困在人物意識裡**：心理寫實、現代主義、不可靠自述。
- **想讓讀者參與解題**：古典偵探。
- **想讓讀者承受不確定性**：間諜、恐怖、哥德。
- **想讓讀者理解一套世界如何運作**：科幻、奇幻、歷史、反烏托邦。
- **想讓讀者追蹤龐大關係網**：章回群像、家族史詩、武俠。
- **想讓讀者投入關係選擇**：愛情、成熟成人、心理寫實。
- **想處理身體親密及其後果**：成人親密；同時載入心理行為與同意／權力規則。

## 快速路由問題

1. 本書最核心的閱讀承諾是解謎、關係、恐懼、世界推想、人物內在，還是歷史／制度？
2. 讀者應知道得比主角多、少，還是相同？
3. 最重要的衝突發生在外部事件、關係、制度、身體，還是自我敘事？
4. 結局需要解答、選擇、代價、世界認知，還是餘韻？
5. 哪種風格若使用過量，最可能傷害此故事？

以答案選一個主引擎，再選敘事鏡頭和語言質地。成人類通常是內容／關係模組，可疊加於寫實、驚悚、歷史、愛情或其他主引擎；角色設定、內容尺度、界線與呈現方式依專案契約執行。
