# 來源、研究範圍與使用說明

本技能不是文學史排名，也不宣稱一位作家只有一種技巧。代表人物用來指出可研究的工藝傳統；具體結論應回到作品、作家訪談、可靠文學研究與類型史交叉查證。

## 建議來源層級

1. **原始作品**：分析場景、視角、資訊與時間結構；避免大量引文。
2. **作家本人談創作**：訪談、書信、隨筆、講座；作家自述不等同作品唯一解釋。
3. **學術／權威類型史**：確認流派、年代、文化與概念，不把網路口號當定論。
4. **編輯、評論與工藝書**：轉成可測試建議，不當普遍法則。
5. **粉絲分析與論壇**：只作線索或讀者反應，不支撐重要歷史主張。

- *The Paris Review*, “Writers at Work” interviews：https://www.theparisreview.org/interviews

## 代表人物使用界線

- **在世作者**：只提煉高層工藝，如敘事距離、類型結構、資訊節奏和世界後果；不輸出「完全像某作者」的聲紋仿寫。
- **已故作者**：可更具體討論技術，但仍不拼貼原句或把作品內容換名重製。
- **中文／翻譯文學**：必須區分原文風格與譯者選擇。只讀翻譯時，不把句法特徵全部歸給原作者。
- **古典作品**：注意版本、作者歸屬、續書、編校與後世改寫差異。
- **文化流派**：魔幻寫實、武俠、哥德等應研究其歷史和社會脈絡，不當成裝飾包。

## 成人題材研究邊界

- 區分成熟文學、愛情類型、情色敘事與露骨程度；它們可以重疊但不等同。
- 代表人物如 D. H. Lawrence、Anaïs Nin、James Baldwin、Marguerite Duras、Colette、Edith Wharton 等，只作工藝入口，不表示其作品價值觀全部適用於現代創作。
- 時代作品中的性別、階級、殖民、性傾向與同意觀念需批判性轉譯，不直接複製。
- 成人題材的角色年齡、關係性質、同意／界線、權力差、露骨程度及後果由作者寫入專案內容契約；技能據此維持敘事一致性。
- 不同模型／供應商可能另有不可由技能覆寫的內容規則；更換模型時應依實際能力調整尺度或呈現方式。
- 描寫傷害不等於肯定傷害；若作者選擇相關題材，記錄敘事立場、人物理解與後續因果，避免模型自行改寫設定。

## 如何新增代表人物

新增前回答：
1. 他／她代表哪一個目前缺少的工藝問題？
2. 能否提出至少三條可泛化、可檢查的技巧？
3. 哪些只是表面聲紋，不應收入？
4. 技巧適用什麼故事，不適用什麼故事？
5. 有哪些文化、年代、倫理與翻譯限制？
6. 是否在世？若是，輸出需要提高抽象層級。

若只是重複現有技巧，不必為增加名字而擴充。
