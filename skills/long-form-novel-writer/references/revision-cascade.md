# 快照與改綱級聯

## 何時快照
改寫已定稿章、改變世界規則／人物身分／關鍵事件／伏筆意義、批量更新前。快照保存 manifest（時間、原因、檔案 hash、正典邊界），不覆蓋正文。

## 級聯流程
1. 先 snapshot。
2. 列出直接受影響檔與 Graph 節點，並標記 `cascade_pending`。
3. 沿依賴關係擴展至摘要、時間線、狀態、伏筆、未來章綱、讀者帳本、索引與 context pack。
4. 作者確認改動範圍後，更新來源正典，再更新衍生檔。
5. 重建 index/context pack，通過 gate 後清除 stale。

不要把「圖譜找到的關係」當成改寫正典的理由；圖譜只證明需人工複核的位置。
