# 場景描述技術

## 描寫由視角和欲望過濾

同一房間不應被每個人看成同一組物件。人物會優先注意：
- 能幫助或阻礙當下目標的事物
- 職業訓練使他無法忽略的異常
- 與恐懼、羞恥、記憶或欲望相關的細節
- 權力位置：出口、座次、價格、乾淨程度、武器、目光

## 選擇有功能的細節

細節至少承擔一項：
1. 定位空間與行動可能性
2. 顯示人物觀點或關係
3. 建立氣氛但不直接命名情緒
4. 埋設稍後會用到的物件／限制
5. 顯示時間、制度、階級或職業現實

若不承擔功能，刪除或壓縮。

## 空間可讀性

動作場景先讓讀者知道：
- 人物相對位置
- 出入口與障礙
- 關鍵物件距離
- 光線、噪音或視野限制

不必畫地圖式逐項說明；在人物移動和選擇中逐步建立。物件位置一旦影響情節，要納入連續性。

## 感官使用

不要機械地每場列五感。選擇最能區分場所或影響行為的 1–3 種感官。氣味、溫度、觸感和聲音常比視覺更能建立身體處境，但仍須符合視角人物注意力。

## 情緒的間接呈現

避免「心跳加快＝緊張」反覆使用。可寫：
- 注意範圍變窄或黏在錯誤細節
- 熟練動作出現微小失誤
- 人物過度控制語氣、物件或秩序
- 對時間、距離、聲音產生主觀偏差
- 使用慣常防衛：玩笑、糾正、照顧別人、離開

身體反應有個體差異，不能每人同一套。

## 比喻與意象

- 比喻來源應符合人物經歷和作品語體。
- 一段通常保留最準確的一個，不疊三個近義比喻。
- 核心意象重複時要改變含義：安全 → 束縛 → 失去 → 自主選擇。
- 不用華麗比喻掩蓋空間、動作或因果不清。

## 描寫節奏

- 危急時：句法和觀察可收窄，但不要因此讓空間變模糊。
- 安全時：可容許更長聯想，但仍受當下目的約束。
- 新場所：先給能做決策的資訊，再補氣氛。
- 熟悉場所：寫變化與異常，不重新導覽。

## 快速檢查

- 描寫是否只有此視角人物才會這樣選？
- 刪除此細節會損失空間、人物、氣氛或伏筆嗎？
- 人物能在當下注意這麼多嗎？
- 動作所需的位置和距離是否清楚？
- 是否重複上一段已傳達的情緒？
- 是否使用過度熟悉的身體反應或比喻？
